Codexa Frontend

Quick start

1. Install dependencies

```bash
npm install
```

2. Run development server

```bash
npm run dev
```

3. Build for production

```bash
npm run build
```

4. Preview production build locally

```bash
npm run preview
```

Notes

- The app entry is `src/main.tsx` and the root HTML is `index.html`.
- The project uses Vite and Tailwind CSS.
- To deploy, you can use Vercel or any static host that serves the `dist` folder produced by the build.
